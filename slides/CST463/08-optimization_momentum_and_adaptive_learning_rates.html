Learning objectives

  • Feel why plain SGD can stall, before seeing any fix
  • Sort every fix into one of two buckets: tune the step size, or tune what we compute from the gradient
  • Read Adam’s update rule as “momentum and Adagrad, combined” – and know where that combination gets messy
  • Recognize the canonical Adam + scheduler training loop as a small edit to the loop already written by hand

Why plain SGD gets stuck

Same loop, a harder landscape

Where we left off

  • Every epoch: pull a mini-batch from a data loader, run the forward pass, compute the loss
  • loss.backward() computes the gradient; optimizer.step() applies it
  • So far, optimizer has always meant plain torch.optim.SGD, with one fixed learning rate for the whole run

A harder landscape

Real loss surfaces aren’t smooth bowls – they have a rough overall trend and bumps along the way

  • Especially once we have multiple layers!

Plain gradient descent, as code

def step__gradient_descent(x, grad, eta):
    return x - eta * grad
  • x: the current parameter value
  • grad: the gradient of the loss with respect to x, at this step
  • eta: the learning rate – one fixed number, for the whole run
  • Every optimizer for the rest of this lecture is a variation on this exact function – same shape, one more ingredient at a time

def server(input, output, session):
    state = reactive.Value({"x": X0, "step": 0, "diverged": False})
    history = reactive.Value([])

    def do_step():
        s = state.get()
        if s["diverged"]:
            return
        grad = fp(s["x"])
        x_new = s["x"] - input.lr() * grad
        step = s["step"] + 1

Two knobs we can turn

Two different kinds of fix

The Big Idea

w \leftarrow w - \eta \dfrac{\partial L}{\partial w} has two parts:

  • \eta: our learning rate
  • \dfrac{\partial L}{\partial w}: Our gradient step calculation

We can tweak these to get better performance!

The two buckets

Tune the step size itself

  • The learning rate \eta doesn’t have to be one fixed number
  • Shrink, grow, or otherwise schedule it as training goes on

Tune what we compute from \nabla L

  • Instead of stepping on the raw gradient, use a running summary of it
  • Carry momentum forward, or scale each parameter’s step by its own gradient history

Learning rate scheduling

Let \eta change over time

Decaying the learning rate

\eta_t = \eta_0 \cdot \gamma^t \qquad (\gamma < 1)

def scheduled_lr(eta_0, gamma, t):
    return eta_0 * gamma ** t
  • \eta_0: the starting learning rate – large enough to clear early obstacles
  • \gamma: the decay factor – how much of the previous step size survives each step
  • t: the step count – the update itself is still step__gradient_descent, just called with eta = scheduled_lr(eta_0, gamma, t) instead of one fixed number



The idea is that we decrease the step over time

Adagrad

Scale the step by how much a parameter has already moved

The key insight

Remember how in Gradient Descent with \hat y = wx + b we saw big changes in w but slow changes in b?

w and b often need different amounts of updating

  • A parameter whose gradient has been small likely hasn’t found its value yet
    • It should have a big step to get it where it is going
  • A parameter who has had big gradients has moved a lot
    • That sounds like a job for a learning rate reduction so it doesn’t overshoot

The math behind it

s \leftarrow s + g^2 \qquad x \leftarrow x - \frac{\eta}{\sqrt{s}+\epsilon}\,g

  • g: the gradient of the loss with respect to this one parameter, at this step
    • e.g. \frac{ \delta L }{ \delta w_0 }
  • s: a running sum of this parameter’s squared gradients so far – grows every step, never shrinks
  • \epsilon a small number to make sure we don’t divide by 0 while s is near to 0

Dividing \eta by \sqrt{s} makes step sizes shrink as we apply more gradients


def step__adagrad(x, s, grad, eta, eps=1e-8):
    s = s + grad ** 2
    return x - eta / (s**0.5 + eps) * grad, s
  • Same shape as step__gradient_descent – the only change is eta becomes eta / (s**0.5 + eps), a different effective learning rate for every parameter

Momentum

Keep a memory of where we were heading

Carrying velocity forward

v \leftarrow \beta v - \eta \nabla L(x) \qquad x \leftarrow x + v


def step__momentum(x, v, grad, eta, beta):
    v = beta * v - eta * grad
    return x + v, v


  • \beta : how much of the previous step’s velocity survives into this one
    • Will be in the range (0, 1]
  • Gradient Descent with momentum behaves like a rolling ball
    • If the gradient keeps pointing the same general direction, v gets bigger
    • If the gradient reverses, momentum still carries some of the old direction forward for a step or two, instead of stopping instantly

Adam

Momentum and Adagrad, combined

What if we did both?

Adagrad (and learning rate adjustment)

  • Scales the learning rate at each step
  • Ensures we don’t overshoot late in training

Momenum

  • Keeps the gradient moving in the same direction
  • Allows us to skip out of local maxima


Adam combines these:

  • Track where the gradient has been pointing (momentum’s idea)
  • Track how much it’s moved so far (Adagrad’s idea)

Adam: Updates

m \leftarrow \beta_1 m + (1-\beta_1)g s \leftarrow \beta_2 s + (1-\beta_2)g^2 x \leftarrow x - \frac{\eta}{\sqrt{s}+\epsilon}\,m

  • m: running average of the gradient itself
    • the same mechanism as momentum’s v, but renamed since it isn’t the position update, just the averaged direction
  • g: the gradient of the loss with respect to this one parameter, at this step (e.g. \frac{ \delta L }{ \delta w_0 })
  • s: a running average of the squared gradient
    • The same as Adagrad, but averaged instead of summed
  • \beta_1 and \beta_2 are both in the range of (0,1] and control how much we use history
  • (We’re leaving out \epsilon this time for clarity)

The same equations, as code

def step__adam(x, m, s, grad, eta, beta1=0.9, beta2=0.999, eps=1e-8):
    m = beta1 * m + (1 - beta1) * grad
    s = beta2 * s + (1 - beta2) * grad ** 2
    return x - eta * m / (s**0.5 + eps), m, s
  • Line 1: step__momentum’s update, renamed
  • Line 2: step__adagrad’s update, renamed and averaged instead of summed
  • Line 3: the same shape as step__gradient_descent
    • grad is replaced by m
    • eta is replaced by eta / (s**0.5 + eps)

What Adam is actually doing

Instead of just tuning the step size or the gradient, Adam does both

  • It makes use of momentum to keep the gradient moving over local maxima
  • It scales the learning rate per parameter every step so we don’t move too much


Adam works well by using both at once, not just choosing one

def server(input, output, session):
    state = reactive.Value({"x0": X0, "x": X0, "m": 0.0, "s": 0.0, "step": 0, "diverged": False})
    history = reactive.Value([])

    def do_step():
        s = state.get()
        if s["diverged"]:
            return
        grad = fp(s["x"])
        lr = input.lr()
        if input.adam():
            t = s["step"] + 1
            m_new = BETA1 * s["m"] + (1 - BETA1) * grad
            s_new = BETA2 * s["s"] + (1 - BETA2) * grad**2
            m_hat = m_new / (1 - BETA1**t)
            s_hat = s_new / (1 - BETA2**t)
            x_new = s["x"] - lr * m_hat / (np.sqrt(s_hat) + EPS)
        else:
            m_new, s_new = 0.0, 0.0
            x_new = s["x"] - lr * grad
        step = s["step"] + 1
        if not np.isfinite(x_new) or abs(x_new) > DIVERGED_LIMIT:
            state.set({**s, "step": step, "diverged": True})
            return
        history.set((history.get() + [x_new])[-TRAIL_LEN:])
        state.set({"x0": s["x0"], "x": x_new, "m": m_new, "s": s_new, "step": step, "diverged": False})

    @reactive.effect
    @reactive.event(input.step_once)
    def _():
        do_step()

    @reactive.effect
    @reactive.event(input.step_ten)
    def _():
        for _ in range(10):
            do_step()

    @reactive.effect
    @reactive.event(input.reset, input.x0)
    def _():
        history.set([])
        state.set({"x0": input.x0(), "x": input.x0(), "m": 0.0, "s": 0.0, "step": 0, "diverged": False})

    @output
    @render.text

        if s["diverged"]:

        return f"Step {s['step']}  |  x = {s['x']:.3f}  |  f(x) = {f(s['x']):.3f}"

    @output
    @render.plot
    def walk_plot():
        s = state.get()
        return plot_walk(s["x0"], s["x"], history.get(), s["diverged"])

import numpy as np

X0 = -6.0
TRAIL_LEN = 40
DIVERGED_LIMIT = 1e4
BETA_MOMENTUM = 0.9
BETA1_ADAM, BETA2_ADAM = 0.9, 0.999
DECAY_GAMMA = 0.9
EPS = 1e-8


def f(x):
    return 0.05 * x**2 - 2 * np.sin(x)


def fp(x):
    return 0.1 * x - 2 * np.cos(x)


def plot_walk(x0, x_current, history, diverged):
    fig, ax = plt.subplots(figsize=(7, 3.2))
    xs = np.linspace(-12, 10, 400)
    ax.plot(xs, f(xs), color="steelblue", linewidth=2, zorder=1)

    trail = [x0] + history
    n = len(trail)
    for i in range(1, n):
        age = n - i
        alpha = max(0.08, 1 - (age - 1) / TRAIL_LEN)
        ax.plot([trail[i - 1], trail[i]], [f(trail[i - 1]), f(trail[i])],
                color="tab:red", alpha=alpha * 0.7, linewidth=1.2, zorder=2)
        ax.plot(trail[i], f(trail[i]), "o", color="tab:red", alpha=alpha, markersize=5, zorder=2)

    if not diverged:
        ax.plot(x_current, f(x_current), "o", color="black", markersize=10, zorder=3)

    ax.set_xlim(-12, 10)
    ax.set_xlabel("x")
    ax.set_ylabel("f(x)")
    fig.tight_layout()
    return fig

def server(input, output, session):
    state = reactive.Value(initial_state(X0))
    history = reactive.Value([])

    def do_step():
        s = state.get()
        if s["diverged"]:
            return

        grad = fp(s["x"])
        lr = input.lr()
        eta_t = lr * (DECAY_GAMMA ** s["step"]) if input.decay() else lr
        optimizer = input.optimizer()

        v_new, s_accum_new, m_new, v_adam_new = s["v"], s["s"], s["m"], s["v_adam"]

        if optimizer == "Plain GD":
            x_new = s["x"] - eta_t * grad
            v_new = 0.0
        elif optimizer == "Momentum":
            v_new = BETA_MOMENTUM * s["v"] - eta_t * grad
            x_new = s["x"] + v_new
        elif optimizer == "Adagrad":
            s_accum_new = s["s"] + grad**2
            x_new = s["x"] - eta_t / (np.sqrt(s_accum_new) + EPS) * grad
        else:  # Adam
            t = s["step"] + 1
            m_new = BETA1_ADAM * s["m"] + (1 - BETA1_ADAM) * grad
            v_adam_new = BETA2_ADAM * s["v_adam"] + (1 - BETA2_ADAM) * grad**2
            m_hat = m_new / (1 - BETA1_ADAM**t)
            v_hat = v_adam_new / (1 - BETA2_ADAM**t)
            x_new = s["x"] - eta_t * m_hat / (np.sqrt(v_hat) + EPS)

        step = s["step"] + 1
        if not np.isfinite(x_new) or abs(x_new) > DIVERGED_LIMIT:
            state.set({**s, "step": step, "diverged": True})
            return

        history.set((history.get() + [x_new])[-TRAIL_LEN:])
        state.set({
            "x0": s["x0"], "x": x_new, "v": v_new, "s": s_accum_new, "m": m_new, "v_adam": v_adam_new,
            "step": step, "diverged": False,
        })

    @reactive.effect
    @reactive.event(input.step_once)
    def _():
        do_step()

    @reactive.effect
    @reactive.event(input.step_ten)
    def _():
        for _ in range(10):
            do_step()

    @reactive.effect
    @reactive.event(input.reset, input.optimizer, input.x0)
    def _():
        history.set([])
        state.set(initial_state(input.x0()))

    @output
    @render.text
    def state_text():
        s = state.get()
        lr = input.lr()
        eta_t = lr * (DECAY_GAMMA ** s["step"]) if input.decay() else lr
        if s["diverged"]:
            return f"Step {s['step']}  |  Diverged! η is too large -- hit Reset and try a smaller value."
        return (
            f"Step {s['step']}  |  effective η this step: {eta_t:.3f}\n\n"
            f"x = {s['x']:.3f}  |  f(x) = {f(s['x']):.3f}"
        )

    @output
    @render.plot
    def walk_plot():
        s = state.get()
        return plot_walk(s["x0"], s["x"], history.get(), s["diverged"])
